# Governance

## Maintainers

The following people are Maintainers for `chimera-bench`:

- Zebulon Rouse-Frantzich (@zebulonfrantzich)

## Changing maintainers

- Changes to this file must be made through a pull request.
- A maintainer change pull request must be approved and merged by an existing
  Maintainer listed in this file.
- If this repository is transferred to a successor repository, the then-current
  Maintainers may designate that successor in writing in this repository or in
  the successor repository's initial documentation.

## Emergency succession

- If no listed Maintainer is reachable for 180 consecutive days, a repository
  owner or administrator may appoint replacement Maintainers by updating this
  file, with a public note describing the reason for the change.
